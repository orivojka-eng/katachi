## 📖 The Story Behind Katachi

**Katachi (かたち)** — meaning *form, shape, and figure* — is a celebration of spatial harmony and Belgian architectural design. In an era dominated by transient fast furniture, QUOLYTECH Atelier set out to build digital and physical experiences that honor materials that breathe: solid European white oak, brushed blackened steel, and raw natural Belgian linen.

This web application represents the digital flagship showroom for the Katachi collection. Every interaction, from the weightless scroll transitions to the tactile quick-look modals, is calibrated to reflect the quiet confidence of minimalist architecture.

---

## ✨ Key Functions & Experience

### 1. Cinematic Spatial Hero
- **Ambient Momentum Parallax**: Smooth scaling and vertical depth displacement driven by Framer Motion scroll position.
- **Typographic Cascade**: Staggered letterform animations welcoming visitors with architectural clarity.
- **High-Density Imagery**: Optimized Next.js image loading showcasing Belgian interior vignettes.

### 2. Interactive Product Showroom
- **Curated Catalog**: Handcrafted chairs, modular oak dining tables, boucle loveseats, and architectural seating.
- **Instant Quick-Look Modal**: Inspect dimensions, upholstery selections, and material origins without navigating away.
- **Dynamic Price Formatting**: Currency formatting with real-time stock availability indicators.

### 3. Materials & Craftsmanship Story
- **Interactive Swatch Selector**: Explore solid oak grains, patinated bronze, matte powder-coated steel, and woven bouclé.
- **Philosophical Quotes**: Embedded atelier manifestos highlighting timeless, multi-generational durability.

### 4. Direct Newsletter & Atelier Updates
- **Client Ingestion**: Interactive subscription input with instantaneous feedback and animated confirmation badges.
- **Privacy First**: Fully compliant disclaimer and unsubscription transparency.

### 5. Architectural Footer & Identity
- **Dedicated Hallmark**: High-contrast "Made by QuolyTech" authenticity badge.
- **Responsive Layout**: Adapts gracefully across mobile, tablet, and ultra-wide desktop viewports.

## 🛠️ Technology Stack

- **Framework**: Next.js 15 (App Router, Turbopack)
- **Library**: React 19
- **Styling**: Tailwind CSS 4 + Custom Architectural Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide Icons
- **Font**: Inter Display via Google Fonts

## 🚀 Quick Start & Local Development

```bash
# Clone the repository
git clone https://github.com/orivojka-eng/katachi.git

# Navigate to directory
cd katachi

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev -- -p 3007
```

Open [http://localhost:3007](http://localhost:3007) in your browser.
